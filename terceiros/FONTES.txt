OpenSCAD WebAssembly
Versão 2025.03.25.wasm24456. Commit ce5039f8a9545ad5a8cf197b3ca11c0939bc67f1.
A distribuição upstream usa GPL-2.0-or-later com a exceção CGAL em seu COPYING. CADAM fornece o motor no contexto de sua distribuição GPLv3. As licenças, os avisos e a oferta upstream acompanham este arquivo. O ZIP do playground contém os binários. Para obter o código-fonte, use a revisão abaixo com os respectivos submódulos.

Fonte exata, histórico e referências dos submódulos
https://github.com/openscad/openscad/tree/ce5039f8a9545ad5a8cf197b3ca11c0939bc67f1

Em um terminal com Git:
  git clone --no-checkout https://github.com/openscad/openscad.git
  cd openscad
  git checkout --detach ce5039f8a9545ad5a8cf197b3ca11c0939bc67f1
  git submodule update --init --recursive

Receitas públicas do ambiente de compilação, contendo o Makefile com as fontes das dependências, o Dockerfile.base e os patches. O fonte do visualizador está em fontes/visualizador.mjs. Para gerar o módulo JavaScript do visualizador, use three@0.169.0 e esbuild com os argumentos --bundle --minify --format=iife. O HTML incorpora o resultado em gzip e base64 no recurso viewer.

Fontes do projeto
https://github.com/MoraesGil/haste-oculos-lente-panoramica
index.html contém os scripts legíveis da interface, cotas e cortes. fontes/worker.js contém a integração com o motor. modelos/haste-oculos.scad contém a fonte CAD usada pelo editor. Para obter uma variante com os valores atuais, selecione a peça e use Baixar SCAD.
